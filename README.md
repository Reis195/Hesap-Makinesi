# Hesap-Makinesi
Bu proje, yaklaşık iki sene öncesinde pythonda kendimi geliştirmeye çalıştığım zamanlarda yapmış olduğum projedir. Detaylı bir hesap makinesi projesi olduğunu düşünüyorum. İçinde bir çok özellik bulunmaktadır. Programda hiçbir arayüz tasarımı bulunmamaktadır. Daha çok işin mantıksal tarafına odaklanılmıştır. Ayrıca o zamanlar açık konuşmak gerekirse ara yüz tasarımlarına dağir pek bir bilgim yoktu desem yanlış konuşmış olmam. Kodda "Numpy" isimli kütüphane kullanılmıştır. Eğer ki bilmiyorsanız, Numpy isimli kütüphane python yazılım dilinde yaptığınız veyahutta yapacağınız matematiksel işlemler için bambaşka bir dünya sunar. İleri seviye bir kütüphanedir, fakat kullanımını öğrenirseniz büyük projelerde size faydası dokunacaktır. Kodumda eksiklikler olduğunun bende farkındayım.
