# Hesap-Makinesi
Bu proje, yaklaşık iki sene öncesinde pythonda kendimi geliştirmeye çalıştığım zamanlarda yapmış olduğum projedir. Detaylı bir hesap makinesi projesi olduğunu düşünüyorum. İçinde bir çok özellik bulunmaktadır. Programda hiçbir arayüz tasarımı bulunmamaktadır. Daha çok işin mantıksal tarafına odaklanılmıştır. Ayrıca o zamanlar açık konuşmak gerekirse ara yüz tasarımlarına dağir pek bir bilgim yoktu desem yanlış konuşmış olmam. Kodumda eksiklikler olduğunun bende farkındayım. Şu an İnteraktif Talep Sistemi isimli uygılamamı geliştirmekle meşgulüm. İyi günler dilerim
